# DART 전자공시
이 스킬은 금융감독원 전자공시 시스템(DART)의 Open API를 파이썬 라이브러리 `OpenDartReader`와 CLI 인터페이스 `dart`를 통해 
투자에 필요한 공시 데이터를 손쉽게 조회·분석할 수 있도록 돕는 스킬입니다.

## What this skill does
공시 목록 검색, 기업 개황 조회, 재무제표 분석, 지분공시 추적, 주요사항보고서 조회, 공시 원문 다운로드 등 
전자공시 데이터를 다양한 관점에서 활용할 수 있는 기능을 제공합니다.

## When to use
* "삼성전자 최근 공시 목록 보여줘"
* "삼성전자 2024년 재무제표 조회해줘"
* "국민연금공단이 최근 보유비율 변동 신고한 내역 찾아줘"
* "삼성전자 주요 주주 현황 알려줘"
* "최근 유상증자 공시 찾아줘"
* "삼성전자 배당 현황 알려줘"
* "20220816001711 공시 원문 다운로드 해줘"
* "삼성전자, SK하이닉스, 현대자동차 재무제표 비교해줘"
* "삼성전자 고유번호 알려줘"
* "오늘 나온 정기공시 목록 보여줘"
* "2026-05-04 정기공시 목록 보여줘"

## When not to use
* 투자 의견이나 매수/매도 추천을 요청하는 경우
* 실시간 주가 시세를 조회하는 경우 (→ `kis-utils` 스킬 사용)
* 주식 매매 주문을 실행하는 경우 (→ `kis-utils` 스킬 사용)
* 가상자산(암호화폐) 관련 조회·거래 (→ `upbit-utils` 스킬 사용)

## Prerequisites

### DART API 인증키 발급
DART Open API를 사용하려면 인증키가 필요합니다.

1. [DART 오픈 API](https://opendart.fss.or.kr/) 홈페이지에 접속하여 회원가입 후 로그인합니다.
2. **[인증키 신청/관리]** 메뉴에서 API 인증키를 발급받습니다.

### 환경변수 설정
발급받은 API 인증키를 홈 디렉토리의 `.env` 파일에 설정합니다. 
기존 `.env` 파일이 있다면 아래 항목만 추가합니다.

```
DART_API_KEY="발급받은_API_KEY"
```

#### 윈도우 PowerShell
```powershell
$envFile = Join-Path $HOME ".env"

# 기존 .env 파일에 DART_API_KEY가 없으면 추가
if (Test-Path $envFile) {
    $content = Get-Content $envFile -Raw
    if ($content -notmatch 'DART_API_KEY') {
        Add-Content $envFile "`nDART_API_KEY=`"발급받은_API_KEY`""
        Write-Host "DART_API_KEY를 .env 파일에 추가했습니다."
    } else {
        Write-Host "DART_API_KEY가 이미 설정되어 있습니다."
    }
} else {
    'DART_API_KEY="발급받은_API_KEY"' | Set-Content -Encoding UTF8 $envFile
    Write-Host ".env 파일을 생성하고 DART_API_KEY를 설정했습니다."
}
```

#### 우분투 리눅스 Bash
```bash
ENV_FILE="$HOME/.env"

if [ -f "$ENV_FILE" ] && grep -q 'DART_API_KEY' "$ENV_FILE"; then
    echo "DART_API_KEY가 이미 설정되어 있습니다."
else
    echo 'DART_API_KEY="발급받은_API_KEY"' >> "$ENV_FILE"
    echo "DART_API_KEY를 .env 파일에 추가했습니다."
fi
```

### OpenDartReader 설치

다음과 같이 설치합니다.

```bash
uv tool install opendartreader
```

이미 설치되어 있고 업그레이드가 필요하다면 다음과 같이 설치합니다.

```bash
uv tool install --upgrade opendartreader
```

## 활용법

CLI 인터페이스를 사용합니다.

```bash
# 공시 검색 (삼성전자, 2024년 이후 전체) - 기본 JSON 출력
dart list "삼성전자" --start "2026-01-01"

# 공시 검색 (삼성전자, 2025년 전체) - 사람이 보기 좋은 형식
dart list "삼성전자" --start "2025-01-01" --end "2025-12-31" --pretty

# 2026-05-04 하루 동안 모든 기업의 공시 목록
dart list --start "2026-5-4" --end "2026-5-4" --pretty

# 2026년 1분기 정기 공시 목록 (최종 보고서만)
dart list --start "2026-01-01" --end "2026-03-31" --kind "A" --pretty

# 기업 개황 조회 (기본 JSON 출력)
dart company "삼성전자"

# 기업명 검색으로 개황 조회 (다수의 회사가 검색 됩니다)
dart company-by-name "삼성전자"

# 재무제표 조회 (JSON 출력)
dart finstate "삼성전자" 2023

# 재무제표 조회 (여러 기업)
dart finstate "005930, 000660, 005380" 2021
dart finstate "삼성전자, SK하이닉스, 현대자동차" 2025

# 재무제표 XBRL 원본 파일 저장
dart finstate-xml 20220308000798

# 주요 주주 조회
dart shareholders "삼성전자"

# 사업보고서 특정 항목 조회
dart report "삼성전자" "배당" 2023

# 공시 서류 원문 다운로드 (.html 저장)
dart document 20220816001711

# 공시 서류 원문 모두 다운로드 (다수의 .html 저장)
dart document-all 20220816001711

# 하위 문서 제목과 URL
dart sub-docs 20220308000798
dart sub-docs 20220308000798 --match=감사의견

# 종목코드 혹은 기업명으로 고유번호 얻기
dart find-corp-code 005930
dart find-corp-code 삼성전자

# 첨부 파일 모두 다운로드
dart attach-files 20221111000817

# 제출자명으로 목록 검색
# type: "정기공시","주요사항보고", "발행공시", "지분공시", "기타공시", "외부감사관련", "펀드공시", "자산유동화", "거래소공시", "공정위공시"
dart list-presenter 국민연금공단 --start 2026-01-01 --end 2026-04-30 --type 지분공시
dart list-presenter 삼성전자 --start 2026-01-01 --type 주요사항보고
```

모든 명령어 뒤에 `--pretty`를 붙이면 사람이 읽기 좋은 형식으로 출력됩니다.

## 투자 활용 시나리오

### 시나리오 1: 기업 실적 분석
1. `dart finstate "삼성전자" 2024` 로 최신 재무제표 조회
2. `dart report "삼성전자" "배당" 2024` 로 배당 정책 확인
3. `dart report "삼성전자" "직원" 2024` 로 인력 현황 파악

### 시나리오 2: 기관투자자 지분 변동 추적
1. `dart list-presenter 국민연금공단 --start 2026-01-01 --type 지분공시` 로 국민연금 투자 동향 확인
2. `dart shareholders "삼성전자"` 로 대량보유 현황 파악
3. 관심 공시의 접수번호(`rcp_no`)로 `dart sub-docs <rcp_no>` 를 통해 상세 문서 확인

### 시나리오 3: 기업 이벤트 모니터링
1. `dart list --start "2026-05-01" --kind "B"` 로 최근 주요사항보고 확인
2. `dart event "관심기업" "유상증자"` 로 자본 변동 이력 파악
3. `dart event "관심기업" "전환사채발행"` 로 CB 발행 이력 확인

### 시나리오 4: 동종업계 재무 비교
1. `dart finstate "삼성전자, SK하이닉스, 마이크론" 2024` 로 반도체 업종 비교
2. 매출액, 영업이익, 당기순이익 등 주요 항목 비교 분석

### 시나리오 5: 정기보고서 심층 분석
1. `dart list "삼성전자" --start "2024-01-01" --kind "A"` 로 정기보고서 목록 확인
2. `dart sub-docs <rcp_no>` 로 보고서 세부 목차 확인
3. `dart sub-docs <rcp_no> --match=감사의견` 으로 감사의견 문서 찾기
4. `dart attach-files <rcp_no>` 로 재무제표 엑셀 파일 다운로드

| 명령어 | 설명 |

모든 명령어 뒤에 `--pretty`를 붙이면 사람이 읽기 좋은 형식으로 출력됩니다.

## Failure modes
- DART API KEY가 유효하지 않은 경우 실행을 중단하고, DART 오픈 API(https://opendart.fss.or.kr/)에서 인증키 발급 절차를 안내합니다.
- `.env` 파일에 `DART_API_KEY`가 설정되어 있지 않은 경우 환경변수 설정을 먼저 안내합니다.
- API 호출 제한(분당 1,000회)을 초과한 경우 일정 시간 대기 후 재시도하도록 안내합니다.
- 종목코드나 기업명이 잘못 입력된 경우 유사한 기업명을 `dart company-by-name`으로 검색하도록 제안합니다.
- 수신한 API의 에러 메시지를 사용자에게 그대로 전달하지 말고, 사용자 친화적인 메시지로 변환하여 전달합니다.

## Best practices
* 기업명과 종목코드 모두 사용 가능하지만, 정확한 조회를 위해 6자리 종목코드 사용을 권장합니다.
* 대량 데이터 수집 시 API 호출 제한(분당 1,000회)을 고려하여 적절한 간격을 두고 요청합니다.
* 공시 목록 검색 시 기업을 특정하지 않으면 최대 3개월까지만 조회 가능하므로 기간을 적절히 설정합니다.
* `--pretty` 플래그를 사용하면 사람이 읽기 좋은 형식으로 출력되고, 기본 출력은 JSON이므로 자동화 파이프라인에 적합합니다.
* 재무제표 비교 시 동일 연도의 데이터를 사용하여 비교의 정확성을 확보합니다.
* 접수번호(`rcp_no`)는 공시 원문 조회, 하위 문서, 첨부 파일 등 여러 명령어에서 공통으로 사용되므로 메모해두면 편리합니다.
